## 打开

从 [页面总览](pages/index.html) 选择一个步骤；也可以直接打开任一HTML。无需安装、联网、构建或启动服务。共享wireframe.css和wireframe.js只提供样式与文档导航。

- 首批：素材/母版 → 任务单 → ASR/对齐 → 源字幕审阅 → 源语检查导出。
- 后续完整多语：源稿确认且目标条件齐备 → 初翻/单位 → 文化 → 语言终审 → 多语交付。
- 仅源语任务不强制经过后续翻译/文化；导航可浏览任何稿件，不表示允许跳过业务前置。

## 页面怎样呈现

每页给出用户所见区块、必要字段/列表、操作入口和操作后状态。原生details或锚点查看其他状态稿；各状态是独立情况，不是同一个任务同时出现互斥结果。表单只读/占位，未保存决定。

简注只解释输入→处理/判断→结果及关联依据。详细字段/规则/统计仍引用03-foundation，不在页面抄整套schema或PRD。八页是重要界面的拆分，不等于修改原七业务阶段或六处理模块。

原型必须展示的候选、人工、低置信/不确定、缺证据、冲突、批量接受、逐条驳回、回滚、失败、停止、升级和发布交接见[页面清单](page-list.md)。

## 示例与边界

所有素材、对白、角色、版本、检查和产物均构造。en-US/US仅作后续任务表单示例，不是已选生产市场。没有真实文件读取、上传、音画播放、ASR、对齐、费用调用、保存、文件生成、签发或平台发布。

缺配置时不把参考阈值当生效硬规则；保存草稿不等于人工确认；生成文件不等于发布。浏览器展示检查只说明页面可读/可达，不能证明业务/模型质量或服务端权限。

历史：[V2过程说明](pages/blueprint.html)、[V2动作稿](action-map.md)、[V1编辑器](pages/legacy-index.html)只作参考。当前入口仅index及八页，不同时维护多套现行原型。
