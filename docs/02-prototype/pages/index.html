B / 八个独立步骤页面

01 / 素材入库

素材接收与母版确认

素材包、可读性/声音、错版与缺项、母版确认；上传成功不等于可以开工。

 02 / 素材入库

任务单与开工检查

用途、语言/市场、范围与输出；源语专用、多语缺项和阶段就绪。

 03 / 听写对齐

ASR与对齐处理

处理方式、输入版本、步骤和产物；处理中、服务失败、停止与未执行。

 04 / 听写对齐

源字幕候选审阅

不确定/缺证据/冲突，接受、编辑、批量预览、驳回、升级与回滚。

 05 / 初翻 · 后续

初翻与单位候选

源文和目标语对照，锁定术语、数字单位与原值保护。

 06 / 文化审校 · 后续

文化风险与人工裁决

问题、证据、适用市场和规则版本；缺依据或冲突时升级人工。

 07 / 语言审校 · 后续

语言审阅与终稿确认

阅读负担、语气与语义保护；人工确认和历史恢复。

 08 / 格式质检与发布交接

检查、文件与交付状态

首批源语出口和后续多语交付；阻断、生成、签发与外部未知分开。
C / 怎么阅读这些页面

表单值、列表和弹出的详情均为构造示例。操作入口用锚点展示“操作后应看到的状态”；所有状态板是独立稿件，不共享任务数据。旁注简述系统处理，不代替主/子PRD。

原文七阶段、六处理模块不因页面数量改变。已认可的数据、规则和指标为本稿依据；示例市场en-US/US及任何规则条目均不表示真实配置已启用。
