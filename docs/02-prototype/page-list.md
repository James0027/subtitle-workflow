## 2. 主要区块与跳转

| 页面 | 用户看到的区块 | 操作入口与反馈 |
| --- | --- | --- |
| 01 | A素材入口、B清单检查、C母版核对、异常状态 | 登记→清单；确认→母版摘要；损坏/无声/错版分别反馈；再去02 |
| 02 | 源语/多语任务字段、阶段检查、缺项责任 | 确认→摘要；缺目标条件→待补；获授权可建源语子任务；条件齐备才交03 |
| 03 | 输入/版本、两条处理路线、步骤与产物 | 展示处理中、候选、已有字幕差异、失败/停止；已有资料保留、后续未执行；交04 |
| 04 | 音画占位、候选对比/问题表、批量预览、历史 | 接受、编辑草稿、明确确认、驳回、升级、逐条批量结果、回滚新修订；源语去08，完整多语去05 |
| 05 | 源/目标对照、术语、单位/日期建议 | 接受/编辑/驳回，锁词未用或缺语境保留问题；确认初稿交06 |
| 06 | 风险列表、证据、适用范围和冲突 | 无证据不能红线；普通人不越权，升级/裁决后仍需按要求审阅 |
| 07 | 译文/改写、可读性/语义、终稿确认 | 语义改变不采纳；未决/无权限/过期修订阻断；回滚需重新确认和检查 |
| 08 | 源语出口、多语质检、失败、文件/签发/外部状态 | 检查失败回责任节点；合格文件生成与人工签发分开；无回执外部未知，不自动发布 |

所有页面可单独打开，左侧导航只浏览稿件；不会在页面间共享或推进任务状态。原生折叠/锚点表示后状态/详情，不提供真实保存、生成或发布。

## 3. 课件要求覆盖

| 要求 | 主要页面 / 可见稿 |
| --- | --- |
| 候选与人工 | 04、05、07；保存草稿与明确确认分开 |
| 低置信/不确定 | 03疑点、04声音不清必审；无有效校准不造分数 |

| 批量接受/逐项结果 | 04预览/跳过/版本失败；05翻译批量 |
| 逐条驳回 | 04、05；保留内容/原因，不自动重跑 |
| 回滚 | 04、07；新修订及受影响检查/签名失效 |
| 失败/停止 | 01材料异常、03服务与停止、08质检失败 |
| 升级/权限 | 04、06、07；责任、依据、未决期间限制 |
| 发布交接 | 08；文件、VALIDATED、PUBLISH_READY及外部未知分开 |

## 4. 倒推线索与待评审

页面用到的Task/Media/Asset/Segment/Candidate/Run/Issue/ReviewDecision/Validation/Artifact/Event，字段以schema为准；动作与门禁以rule-registry为准；展示/决定/人工时间等以metrics及事件契约为准。后续PRD补齐接口与具体任务规格，不在本轮建立新的字段或统计口径。

待评审：页面粒度、主要操作和反馈、两类任务路线、审核职责与信息是否够用；真实素材、语种市场、profile、阈值、预算和身份实现仍待确认。V1/V2标历史，当前清单不将其当新增现行页面。
