## 2. 统计共同约定

### 2.1 单位、样本与去重

| 单位 | 身份与规则 |
| --- | --- |
| 业务任务 | `task_id` 是任务单；一次模块执行为 `run_id`，重试是同一运行下 `attempt_no`，二者不当作新业务样本 |
| 成片分钟 | 按任务约定的权威母版范围取时长并集/60000；一个任务重复运行、导出、切句不增加分母；多个语言交付成本用版本分钟，不能混用 |
| 版本分钟 | 一个约定交付单元的内容时长；按作品/剧集×语言×市场×平台×交付范围去重；修补稿不变成新应交版本 |
| 字幕事件 | `segment_id` 加源修订/评价版本；切分合并需血缘映射回同一评价范围，低质字幕复制不增加独立样本 |
| 建议 | 不可变 `candidate_id`、`candidate_revision=1`、模块及variant_key；内容变化新建candidate_id并记录前后引用；同一候选刷新/重新打开展示只计一次；重跑新候选另留痕并报告重跑比例，不通过重跑放大收益 |
| 错误/风险项 | 人工金标 `gold_item_id/error_id`，按触发跨度、类别、严重性、市场去重；一句可有多个风险，不能用句数充当风险项分母 |
| 术语/实体出现 | `occurrence_id` 是源文某位置的一次应出现实例；同术语出现十次计十次，不计成一个词条，也不让多个模型建议重复计数 |
| 检查与文件 | `validation_id`/`artifact_id` 加内容修订、profile 版本；首轮与最终轮分开，不能只保留最后成功轮 |

主报表纳入指定评估批次所有受理任务，包括失败、放弃、未完成及缺字段任务的状态计数。质量率仅使用具备对应金标和可匹配输出的评价单元；缺失/空输出另报，不能排除后称低错误。挑战集、自然分布集、回归集分报，重复片段按母版/作品聚类，不将挑战集高风险占比外推到生产。

### 2.2 窗口与分层

- 首轮用冻结的 `evaluation_batch_id`、样本/金标/模型/提示词/规则/profile/指标契约版本及 `as_of` 截止时间。后续可做日/周看板，不能用滚动看板替换冻结验收批次。
- `event_at` 为归属依据，`received_at` 用于延迟与重算；二者采用带毫秒精度的UTC RFC3339 timestamp（例如 `2026-10-19T08:00:00.000Z`），间隔计算转换为整数毫秒；展示时标明时区。区间统一左闭右开 `[start,end)`，7日=接受时刻后连续168小时。
- 展示批次归属按首次 `suggestion.shown`；报告冻结展示范围、`decision_cutoff`（人工决定纳入截止）及 `as_of`（观察截止）。有效接受以同一候选第一次保存成功的接受时刻起连续观察168小时；窗内撤销或发生经确认的下游错误即该候选本轮失败，重新接受不能清零窗口或抹去失败；改内容须新candidate并留旧结局。decision_cutoff前未接受者保留展示分母且不进成功分子；已接受但未满窗/缺结局者标待观察/未知，批次结局未齐不出正式有效接受率。迟确认的窗内错误触发报告修订，不能因确认晚而漏计。
- 任务效率批次按任务受理/就绪时间建 cohort，并列截止前未完成数；完成任务 TAT 另报，避免丢掉慢任务。对外交付 cohort 按承诺到期日，不能只看已经交付的版本。
- 必备切片：模块、任务类型（新转写/已有字幕核对/对齐/源语专用/多语）、源/目标语言；有数据时加市场、平台、题材、SNR、风险、供应商、版本、审校人。关键市场/风险桶不能用全局均值抵消。
- 金标/人工评测由两人独立标注、第三人仲裁；记录标注版本、分歧及 Cohen's κ。关键风险 κ<0.70 为课件待启用参考线；先修标注，不把分歧直接算模型错误或正确。

### 2.3 聚合、置信区间与缺失

- 率同时报分子、分母、比例、95%区间和未知数；总体 micro 用分子合计/分母合计，macro 另标。建议接受率依 BRD 先算审校人×语言，再按冻结权重汇总；无业务权重时先等权展示各层观察值，不称总体提升。
- 独立二项样本描述区间用 Wilson 95%；存在同剧、同任务或同审校人相关性时，主比较按作品/任务聚类 bootstrap 10,000次，固定随机种子。配对试验整对重采样；桶内独立作品不足时仅报告描述与区间限制，不能把字幕条数当独立样本数。
- 均值/时长比、P50/P90/P95、配对收益用同一聚类 bootstrap；分位数点估计采用升序线性插值 Type 7，毫秒先计算后展示。少量数据仍展示原始分布并注明不稳定，不虚构显著性。
- 零失败不等于零真实风险：同时给上置信界；无P0金标时 P0召回为“不适用”，不能写100%。零分母统一 null/不适用，未知不是0。
- 缺字段、无金标、账单未到、观察未完各自报告覆盖率；关键质量/成本/计时数据缺失则不批准收益结论。不用缺失剔除后的优秀子集宣称全部达标。
- 迟到事件按 event_id 幂等入账，生成新 report_revision 并说明重算影响；不覆盖已签报告。生产水位线/迟到封账时限待确认，首轮报告使用显式 as_of 与完整性检查。

**人工活跃计时提案（待启用）：** 以有焦点的编辑/回听/审核会话采集活动区间；回听播放须前台且明确处于审校会话。课件“>5分钟空闲”是待校准参数：两活动点间隔>300秒时该间隔整体排除，≤300秒可计活跃，闭会话不向后填时；同时保留原始区间、空闲与显式计时，抽样对照人工计时偏差。切换页面、模型等待不自动代表活跃。阈值、心跳粒度和计时精度未经试采核验，不出正式收益结论。

各行遵守§2；源字段与事件见采集契约。`evaluation_level` 必须区分模型候选、人工确认、最终导出，不将最终人工质量当作模型单独效果。

| MET-OUT-003 导出一致率 | 解析后内容/时间/顺序/样式在约定允许变换内与签发修订一致的包/全部检查包 | 固定规范化策略，逐字段差异留存；有损转换须预先批准，不靠忽略差异通过 |

## 5. 审核行为指标

| metric_id | 公式与约束 |

| MET-REV-001 直接建议接受率 | 未编辑直接接受且截止未撤销的候选数/实际展示的去重候选数；按审校人×语言先求率；批量操作拆到candidate，修改后接受不进分子；回滚同时更新结局 |
| MET-REV-002 7日有效接受率 | 同一展示批次中直接或修改后接受且完整7日无撤销/经确认下游错误的候选数/该批展示候选数；分别报两类分子与待观察、未知数量，不以未发现错误当证明 |
| MET-REV-003 人工编辑率 | 有AI候选且已审事件中被人工改文本的事件数/有AI候选的已审事件数；标点/实质分报；编辑距离=字符Levenshtein/原候选长度，原长0另报；时间轴编辑率、人工补写单列 |
| MET-REV-004 驳回提示负担 | 最终驳回提示数/去重成片分钟，按任务报P50/P90及驳回类别 |

未展示影子候选不能进入接受率分母；接受率不是正确率。记录跳过、无人审、被替换、重跑、撤销与回滚原因。撤销后新版本再接受，不抹去旧版失败；一个已审事件有多个建议时，事件编辑率与建议接受率分母分开。

## 7. 六维、五冲突与责任

| 思考维度 | 主指标/护栏 | 禁止的错误解释 |
| --- | --- | --- |
| 正确性 | ASR、术语、风险召回、语义保护、最终残留 | 以QE/接受率或格式通过证明字幕正确 |
| 可读性 | CPS、行长、断句与人工观看 | 为降低CPS删除否定/人物关系/关键剧情 |
| 文化与法律 | 分市场风险召回、证据、有效规则、人工裁决 | 用高置信代替依据，未知市场等于安全 |
| 可交付性 | Schema pass、导出一致、真实首轮回执 | 将导出文件当平台通过或发布 |
| 可治理性 | 完整追溯、越权/闸门事故数、停止合规 | 指标达标即允许绕过权限或人工确认 |
| 效率 | 完整人工、TAT、成本、失败/返工 | 用生成速度抵消P0，遗漏人工复核或失败成本 |

原文五冲突逐项处理：忠实vs可读→关键语义护栏与CPS同时报告；文化适配vs创作→保留语境与人工裁决，不能用“接受”证明适配正确；统一vs市场→分市场profile和金标，不全局平均放行；效率vs安全→安全底线先满足，P0不能被速度/成本补偿；模型vs术语→锁定译法优先并报出现级召回，不用自然度评分豁免。高层有效限制或两条硬规则冲突转人工，不能强行算某一指标达标。

产品负责人批准指标定义/范围；译审/本地专家对金标与风险裁决负责；数据/工程负责人对采集去重计时与重算负责；算法负责人对评估器、置信校准与分桶负责；交付负责人确认平台回执与截止状态。当前仅职责建议，真实姓名、权限和轮值待主PRD确认，模型不得自行证明自身效果。
