### 1. 处理顺序及职责

已确认音轨/源语言/范围 → 工程固定时间切片 → 模型源语转写 → 工程汇总/时间映射/跨片检查 → 人工回听确认。

| 工作 | 责任 | 本批输出 |
| --- | --- | --- |
| 切音频 | 工程，使用T1.1准备好的音轨；不先按语义/角色切 | 每片标识、实际起止/时长及母版offset、输入hash和来源 |
| 忠实转写 | 音频模型，具体在服型号待验证 | 源语言原话、片内时间候选、听不清/截断疑点；无可用时间时明确未知 |
| 时间还原 | 工程，根据确切offset与时间基准转换 | 母版非负毫秒及来源映射，记录转换，验证区间合法性 |
| 跨片衔接 | 工程检查相邻片段及原声音，必要时交人工 | 断句/重复/漏词风险；保留各片原始结果，不因文字相似盲删 |
| 源语核对 | 人工回听/修改/确认，复用T2.2 | 确认源稿/时间或待处理区间，模型不覆盖人工稿 |

固定时间切片是模型输入组织，不是最终字幕每条固定10秒。台词分句、字幕分行与阅读速度不从切片长度直接推出。时间加offset只保证基准换算，不保证真实语音边界精度。

### 2. 输入与最小输出

必需：已确认音频、用户指定源语言、任务范围及母版时间基准。可选：已确认专名写法/术语、对应脚本摘录；只辅助听写，脚本不能当真实声音复制，缺资料不阻断基本转写。项目素材保持原声音，不先过滤背景声或做角色推理。

每片输出最小内容：对应输入片、原语文字、片内起止候选（若能力支持）、听不清/跨边界截断位置与说明。运行成功/失败、用量、覆盖与模型/Prompt版本由系统记录，不让模型编填。没有说话内容、没有听清、工具失败三种情况不能混为一类。

本批不做角色身份、统一跨片说话人身份、背景音乐/音效分类、剧情分析、译法或文化建议；但重叠说话风险与专名候选清单必须提供，和音频质量、置信依据、时间边界一起构成质量检查层。专名原文不改写成译法，识别不全作为可测漏检问题，不因模型未标就断言无专名。

### 3. 切片及边界处理建议（实现前确认）

先以10秒固定切片作验证候选，尾片保留实际长度不补造声音；同样本可比较20秒再确定默认值。具体长度尚未以用户授权/性能数据冻结。第一版不强制按说话停顿或语义智能切分。

相邻切点可能切断一句话，必须保留相邻片和原音频定位。跨片是否用重叠窗口、少量邻音频或仅提示回听，先用切点样本比较质量/成本再决定；不默认为可自动多调用一次。不能让模型靠剧情补齐被截断的内容，也不能用均分时间冒充精密对齐。相邻内容存在歧义则留疑点，不强行自动修成完整句。

单片失败保留失败范围与已返回结果，整段不能被报告为完整成功。重试/幂等/超时/费用/非法输出策略复用T1.2、09/10子PRD，实际次数和数值待确认，不套课件固定阈值；不因置信低反复同配置试到满意为止。

### 4. 简短转写Prompt与返回格式（审阅草稿，未启用）

Prompt草稿：

> 只根据实际听到的声音转写，不翻译、不润色，不分析角色、剧情或背景音效。若有多人同时说话，标记重叠候选和听不清处；另列人名、地名、品牌及其他专有名称候选。

最小返回建议（模型输出的局部结构草案，不是新系统状态或生产契约）：

| 内容 | 说明 |
| --- | --- |
| text | 整片实际听到的源语文字；无语音可为空，听不清处不造词 |
| timing_candidates | 可选原文片段及片内起止候选；未知留空，不能均分。最终切句/字幕分行仍工程处理 |

| overlap_candidates | 重叠区间/涉及原文及可辨人数候选；未知留空，不冒称稳定说话人身份 |
| entity_candidates | 专名原词、原文位置、类别、资料匹配引用/状态及疑点；未知专名待确认 |

片标识、原始音频引用/hash、母版offset、运行成功/失败、模型/Prompt版本、用量/费用由工程在请求与返回外层关联，不要求模型回填这些系统事实。模型没有返回时间候选时，只能用真实输入片的粗范围展示回听，不能冒称已得到精细逐句时间；精细对齐须验证明确工具能力或交人工。

需共同确认：这一版只听写、不做丰富语义分析；时间候选允许未知；缺可选资料可继续。下一步确定返回结构与切点样本，再试验固定10/20秒及边界策略。无模型调用/外发授权前不做真实调用。

| 能力 | 工程/模型/人工分工及实现建议 | 通过/兜底边界 |
| --- | --- | --- |

| 转写置信依据 | 先核具体模型/接口能否返回原生词/片段分及定义；有则原样保留来源/尺度，后用同语种人工参考校准。无原生分时需要评估独立质量估计器/其他可验证转写接口 | Gemini自报0—1只可算主观判断，不能当正确率；token logprobs/语言概率不等于转写校准分。没有可信数字显示未提供/未校准并交人，不把该兜底当已完成数值置信功能；自动0.92/0.82分档在有效校准前禁用 |
| 时间边界 | 工程固定切片/offset、区间合法性、适用平台间隔；细粒度语音起终点由经验证的时间输出/对齐能力及人工参考核验 | 切片边界不等于句子边界，时间合法不等于同步。P95≤120ms为整体参考误差统计；>250ms必须有参考/回听依据才能判。没参考标未评/需回听，不编绝对偏差；支持人工拖轴 |
| 重叠说话 | 模型/专用工具提出真实候选区间，可辨时保存speaker_count，不辨则未知；工程映射整片并保留跨切点事件 | 首版至少标记重叠与不确定区间交回听，不能按依次说话强合并/覆盖文字；实际300ms门槛须检测器/标注方法验证，不因小于阈值隐藏明显风险；不需要先识别角色名 |
| 专名 | 模型提出人名/地名/品牌/组织/作品或项目定义专名候选；工程再按作用域词表匹配并合并候选，显示原文位置、来源、已确认/待确认；人工补充漏检与确认 | 词表内外都要标，陌生名字不能因为不在表里被漏掉；未确认标黄/待定，不自动带入已确认译法。不直接凭大写/分词断言专名，也不保证模型召回100%；用人工参考量化漏检/误报。将专名确认作为相关下游放行条件，不能伪装成整份人工编辑锁死 |
