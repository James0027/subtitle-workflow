## 1. 范围与需求

从明确源版本和目标分支开始，生成、检查并交出初翻候选。本文消费上下文09提供的受控引用，不建设检索平台，不定义通用审阅状态机。首批源语闭环不运行翻译；本稿定义后续接入行为，真实语种、模型与批次待定。

单模块翻译须已有确认任务、合格源稿和明确目标要求；外部源稿先登记核实，不要求重跑本系统ASR。不把缺输入的多语任务自动降成单模块任务。

## 3. 处理步骤与交接

1. 核对已确认Task、母版关系、范围、源输入和目标variant；默认读已确认源修订。中间源候选仅在有效预授权覆盖且该阶段准入/检查通过时可读，引用具体Candidate，状态仍为AI_PROPOSED。
2. 向09请求本句所需角色/场景、锁词及历史译法。先检查访问权、适用范围和有效版本，再形成manifest；材料缺失标明影响，必需上下文不足时等待补料，不让模型补造人物关系。
3. 将适用锁定译法作为生成约束。局部窗口按已批准策略选择；RULE-TR-003的前后句做法是规则设计基线，实际窗口/扩窗额度待确认，不盲塞整片。
4. 模型仅产出目标语候选及解释。代码校验结构、语言分支、锁词命中、数字/否定/实体变化；QE在已选模型、模式和校准依据下辅助路由，不把分数当正确概率。
5. 锁词漏用阻断该候选；称谓/跨集译法冲突列出双方来源待人核实。关键语义疑似变化挂Issue必审；确定丢失否定、数字或实体时不可作为合格候选推进。
6. 保存成功才回传候选和实际检查范围。默认译员审阅后交文化/单位等适用模块；满足有效预授权与准入时可交中间候选，不能写人工接受事件或HUMAN_APPROVED。

交接携带Task快照、源/目标Ref、variant、manifest、检查结果、未决Issue及责任；04/05/06读取确切输出。无合格译文时返回真实失败/待人工，不用空字符串冒充翻译完成。

## 4. 页面动作与反馈

对应[05初翻与本地化候选](../02-prototype/pages/05-translation.html)的翻译区域；同页单位区由功能05负责。静态示例不能作为真实保存、模型质量或权限证据。

| 动作 | 页面反馈 | 执行端约束 |
| --- | --- | --- |
| 查看源句/候选 | 并排源文本、目标文本、片段时间及版本；默认折叠技术引用 | 查询仍检查项目/对象读取权 |
| 展开锁词/冲突 | 显示源词、要求译法、实际译法、上次确认位置及版本 | 不由模型选择哪个锁词版本生效 |
| 发起翻译/重译 | 处理中防重复提交；成功后展示新候选，失败保留旧稿和原因 | 重译须明确范围及新运行条件，控制由10复查 |
| 接受/编辑/驳回 | 转08处理；编辑完成可保存并提交待审，有审核权限的真人明确接受才有审核通过结果 | 锁词/语义阻断不可直接普通接受；逐条校验版本与权限 |
| 批量处理/继续 | 按条显示成功、拒绝或待补；交接显示具体输出引用 | 不将含失败整批标成功；继续不是内容已确认 |

保存失败保留未提交编辑；并发冲突展示当前修订和待提交差异，不静默合并。锁定/人工确认稿只读，另存候选入口保留。

| 主体 | 负责 | 边界 |

## 6. 局部异常与恢复

| 触发 | 处理 | 恢复条件/责任 |
| --- | --- | --- |
| 缺角色、历史译法或上下文冲突 | 保留原文/旧候选，列缺项及受影响句；不猜性别/称谓 | 负责人补受控引用或人工核实，再按新manifest重跑受影响范围 |
| QE缺模型/校准、规则未有效 | 未评估/待检查，不填虚构分数、不默认自动通过 | 配置合格评价依据或走明确人工路线；仍保留硬检查 |
| 超时、非法结构、空输出 | 记录失败attempt及实际费用；不创建成功候选 | 可重试错误交10，预算或连续重试停止不能被重译按钮绕过 |
| 锁词与模型意见相反 | 保留锁词阻断及模型解释 | 有权人核实适用性；换词条版本需新manifest/Run |
| 输入改版/授权撤销/锁定写入 | 拒绝旧版写入或越权，已产候选保留 | 08处理新修订，10重验授权，只复检受影响依赖 |

## 首版AI设计：初翻稿生成（本轮优先审阅）

2026-10-21用户明确优先初稿生成、文化检测和口语适配。复用本PRD既有候选/版本/审阅规则，本节细化AI任务，不新增平行计划；尚未实现或发起模型调用。

### 输入及上下文

必需：可用源语稿及其确切片段引用、原语言、目标语言和目标市场。输入默认已确认源稿；允许源候选中间流转须遵守原许可/准入，候选身份不变。语义相邻文用于解决跨切片断句、指代；不把固定10秒音频块强迫当完整翻译句。

可选：已有角色/人物关系/称谓资料、剧情或场景说明、术语原词与已确认译法、已确认历史译文、风格要求。只用当前作品/片段范围的适用版本；资料冲突或缺失标待核对，不要求先自动推理整部剧情。音频可供疑点回听，但不默认在每次初翻调用再上传整片音频。

目标语言/市场用于真实初翻时须明确；为讨论样例可使用“墨西哥西语（es-MX）”占位，但不是用户已冻结的项目市场或真实执行配置。

### 上游交接与上下文选择（本轮建议）

初翻读取上游经人工确认的源语稿及准确修订，不直接把10秒音频块当独立完整句。内部继续用JSON/现有Ref，页面以源/目标对照呈现，不在本节另造生产接口。

| 上游信息 | 初翻使用方式 |
| --- | --- |
| 源文、片段/候选ID及修订 | 翻译的准确依据；源文变更后旧译稿标受影响，不静默覆盖 |
| 母版起止时间及精度说明 | 原样关联回听，不靠译文长度重分时间；粗时间不冒充精细边界 |
| 专名清单及确认状态 | 已确认写法/译法作为约束；待确认项带问题，不伪装生效词表 |
| 听不清、截断、重叠等问题 | 涉及关键语义的句子先回听/人工处理，不让初翻模型猜出缺失原文 |
| 运行/输入来源及版本 | 系统保存并供追查，不要求模型重写编号/费用/确认状态 |

上下文建议默认取当前句＋前后各2个可用源语片段，而不是把全部剧情脚本随每句重复发送。原资料可完整接收保存；实际供模型使用时附当前作品/场景相关的角色关系、称谓、术语和必要剧情摘录。首版由明确规则选取，不先建设复杂RAG。

邻文仍无法消除指代/称谓歧义时，使用已提供的同场景资料补充；资料不存在就提待确认，不自动搜索网络或推测人物身份。窗口内没有足够前后句时如实提供已有内容，不补造邻句。原脚本与确认源语冲突时保留源语依据、显示冲突，不能偷偷改源稿。

演示示例（虚构，非真实模型结果）：源句“你别再给我画大饼了。”，演示目标为墨西哥西语，可给初稿“Deja de hacerme promesas vacías.”，简短说明“画大饼”按许诺不兑现的语义表达，不译为食物。是否符合具体剧情/人物语气仍需资料与人确认；后续文化/口语节点继续审阅，不预设这里已完成全部本地化。

### 生成任务和最小输出

任务：生成可供后续审阅的忠实目标语初稿，保留原意、人物关系、称谓、情绪、数字、否定和专名，遵守已确认译法；允许目标语自然表达，不自行改剧情或预先按文化偏好删改。初翻阶段不为满足字数上限删除剧情信息。

页面/业务输出只保留：
- 源句与目标语初稿对照，保留原片段关联；原时间不随翻译变化而擅改。
- term_hits术语使用记录：源词/位置、锁词版本、要求译法及允许词形、实际译法、命中/漏用/冲突及依据；未知专名译法待确认。已确定适用的锁词漏用阻断该候选进入下游，不删除生成结果。
- 简短反向解释/源语语义回述及必要的关键选择说明，和源句、译文并排对照，默认折叠。它是审阅辅助，不证明译文正确；普通句不强迫写大段理由。
- 待核对问题：具体源句、问题及需补的材料/人工决定；没法判断时给一个保守候选并说明，不编造事实。

每句默认一个主候选，确有歧义才给备选；不默认生成多套长版本。不要求模型自行报告已校准质量分。结构/术语/数字等确定性检查由工程，语义和风格由模型/人判断。
