| R08 P0 文化裁决；F-04/08/09 | 有效市场证据和语境形成问题→授权职责可裁决并留依据 | 仅模型高分但无有效规则/语境→待核实，不伪称确定P0或签发 | 普通审阅者解除需高级裁决的阻断→拒绝，问题保留 |
| R09 P1 单位保护；F-05 | 适用单位按策略生成建议→原值/结果/因子/精度可查 | 日期03/04含义不明→请求确认，不按市场猜日期 | 模型向锁定稿直接写入换算值→拒绝，仅可另存候选 |
| R10 P1 语言审校；F-06 | 指定目标稿生成可解释口语/断句建议→审阅者可对比决定 | 改写删除否定→不可采用；CPS更低不能抵消语义违规 | 无终审权限者确认终稿→拒绝，不产生HUMAN_APPROVED |
| R11 P0 人工决定；F-08 | 有权人保存编辑草稿再明确确认→分别留草稿/决定及新修订 | 驳回候选→保留原稿/原因，问题未解决，不自动重跑或完成 | Agent冒充reviewer接受/签发→拒绝；自动执行不记人工接受 |
| R12 P1 批量处理；F-08 | 一批可接受当前候选→逐条决定且共享批次引用 | 批中一条版本改变/必审未完→该条失败/跳过，其他项逐条报告 | 一条不在审阅人权限范围→该条拒绝，不借整批覆盖 |
| R13 P0 版本与锁定；F-08 | 人工确认后新模型运行→另存候选，确认稿不变 | 人工提交expected_revision已过期→拒绝旧版写入并保留待提交内容 | 后续模块写MANUAL_LOCKED正文→拒绝且留实际未写入证据 |
| R14 P0 追踪与幂等；F-10 | 用产物回查task/run/attempt/step、输入输出/manifest及决定→关联齐全 | 同请求重复提交→复用有效结果，重试/失败仍保留，不增业务分母 | 无权限者读取其他项目trace→拒绝，不因日志入口泄露资料 |
| R15 P0 停止与恢复；F-10 | 在已批准预算/次数内的合法运行→真实成本/尝试可查 | 超预算或达到重试停止条件→STOPPED，下一次调用拒绝；未配置预算不启付费 | 无恢复权限者改run/请求重试→拒绝，不清零历史/Task费用 |
| R16 P0 局部修复/回滚；F-08/10 | 有权人恢复历史内容→新修订及决定，受影响检查/签发重新验证 | 上游修订后用旧PASS签新包→拒绝，明确待复检范围 | 无回滚权限者恢复内容→拒绝，历史/当前稿均不被偷偷改写 |
| R17 P0 源语导出/技术检查；F-07/08 | 人工确认源稿按任务规格导出且解析一致→VALIDATED源语文件及记录 | 字幕越范围、未审或解析不一致→失败定位，不称合格导出 | 无产物访问权限者请求文件→拒绝，不因知道artifact_id获得下载权 |
| R18 P0 最终签发/回执；F-07/08/10 | 同一人有审稿/签发权→内容确认及当前包检查完成后同页签发；真实回执才PUBLISHED | 当前包有未决项/内容变更/无回执→分别阻断签发或保持外部未知 | 仅审稿无签发权者请求放行→拒绝签发；Agent无自动外部发布权 |
| R19 P1 指标与目标；F-10 | 冻结批次记录完整人工/等待/返工、失败和版本→按metrics复算目标指标 | 零分母/未满168小时/缺平台回执→不适用或待定，不补0%/成功 | 无范围数据权限者请求报告→拒绝或返回授权聚合，不能暴露受限素材明细 |

规则对应：R01/02/03→RULE-INT-001—004；R04/05/11—16→RULE-SUB-001—004与RULE-GOV-001—004；R06→RULE-ASR-001—004；R07→RULE-TR-001—003；R08→RULE-CULT-001—002；R09→RULE-UNIT-001—002；R10→RULE-ORAL-001—002；R17/18→RULE-OUT-001—003及RULE-SUB-002；R19→metrics/metric-events。它们是交叉索引，不替代注册表的执行条件。

上述19条P0/P1需求各有N/E/A，共57项验收场景。第⑨步据此建立正式用例，补测试数据、前置、操作、观察方式及实现引用；第⑪步填写实际结果。子PRD新增/细分P0/P1同样至少补三类场景，不能只继承主PRD数量当覆盖。当前不存在57项已执行或全部通过的结论。
