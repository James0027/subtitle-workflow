# 字幕项目来源核对

适用于本项目的新结论与变更。先读 [AGENTS.md](../../../AGENTS.md) 及 [来源核对规范](../../../rules/source-check-workflow.md)，后者是流程权威源；本技能只提供入口，不复制业务规则。

- 按规范核对参考工程的同类实际成品、字幕AI Coding课件、本轮相关meeting讲解和work历史决定；不能只读总结。
- meeting必读：先检索 `meeting/week1.txt`、`meeting/week2.txt`，再读命中段落的前后语境。路径相对于AGENTS定义的工作区根目录。每轮只读相关片段，不默认加载整份转写。
- 教师讲解帮助解释意图，不是本项目实测或已批准参数；转写含错字、简化或与课件冲突时，保留出处、差异和处理，不用“老师说过”隐藏取舍。
- 检查需要、依据、判断、产出，以及失败/返工、责任、独立更新和验收；涉及指标写分母、窗口、去重和计算，涉及规则写适用范围、版本、约束和冲突去向。
- 用户授权后，原型与数据/规则/指标可联动推进；不把十二步理解为禁止回看或必须孤立撰写。
- 输出区分原文、教师观点、已确认、设计定义、参考参数与待验证；每部分完成后按规范保存项目总结，不写全局记忆。

本技能不新增外部上传、费用、依赖安装、Git提交、部署或并行委派的授权。
