# 项目状态与日志

先读[项目入口](../../../AGENTS.md)、[日志规范](../../../rules/progress-and-logs.md)及[来源核对规范](../../../rules/source-check-workflow.md)。它们是权威；本技能仅执行记录流程，不再维护一套规范。

- 唯一进度：`docs/00-process/00-02-progress/progress.md`；日志：`docs/00-process/00-01-logs/YYYYMMDD.md`；用户日期时区Asia/Shanghai。
- 会话摘要在工作区外层`work/会话总结/YYYYMMDD.md`，重要决定更新`work/知识索引.md`；源路径按AGENTS定位，不能假设克隆仓库自带外层材料。
- 读当前进度、同日日志和本轮产物/证据，再追加或合并同主题记录；保留旧事实，不重排既有日志来套模板。
- 区分草稿、已确认、已实施、已验证；记录检查范围/实际结果和未决项，模拟/文档检查不算业务验收。
- 有正式开发计划时回写其对应状态；当前没有时不创建计划或伪造Task。迁移技能不代表进入开发阶段。
- 日志落点复用现有文件，不每问一次就新建一篇；记录不构成提交、推送、部署、发消息或改规则的授权。
- 项目经验先留项目记录；不自动升级全局规则/记忆。确有用户授权的规则调整才同步，不以日志流程追加审批关卡。

按需读[操作流程](references/daily-workflow.md)，新日日志参考[精简模板](assets/daily.md)。模板可省略不适用内容，不改造已有当日日志。
